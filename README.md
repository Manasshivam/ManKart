# ManKart 🛒

> **Your City. Your Services. One App.**

ManKart is a hyperlocal super-app built for India, connecting users with local shops, verified professionals, repair services, and a fast-delivery marketplace.

## ✨ Features

| Section | Description |
|---|---|
| 🏪 **Shop Nearby** | Find flower shops, nurseries, pharmacies, bakeries & more near you |
| 👷 **Book a Professional** | Hire verified electricians, plumbers, carpenters, mechanics & more |
| 🔧 **Repair & Install** | Schedule AC, washing machine, TV repairs at your doorstep |
| 🛍️ **Marketplace** | Order groceries, snacks, dairy & more in 30 minutes |

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Design**: Premium dark theme with glassmorphism, `Plus Jakarta Sans` font
- **PWA**: Service Worker + Web App Manifest (installable on Android)
- **Hosting**: GitHub Pages
- **Play Store**: Packaged via [PWABuilder](https://www.pwabuilder.com/) / Trusted Web Activity (TWA)

## 🚀 Deploying to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set **Source** to `main` branch, `/ (root)` folder
4. Click **Save** — your site will be live at `https://YOUR_USERNAME.github.io/ManKart`

## 📦 Publishing to Play Store (via PWABuilder)

1. Deploy to GitHub Pages first (above)
2. Visit [pwabuilder.com](https://www.pwabuilder.com/)
3. Enter your GitHub Pages URL
4. Click **Package for Stores** → **Android**
5. Download the `.aab` (App Bundle)
6. Upload to [Google Play Console](https://play.google.com/console)
